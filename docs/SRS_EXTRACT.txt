1. ARSITEKTUR SISTEM, HAK AKSES & ALUR STATUS (STATE MACHINE)
1.1. Matriks Peran Pengguna & Lisensi Perangkat (14 Akun Tetap)
Sistem menggunakan model lisensi berbasis perangkat/jabatan tetap agar efisien dan kebal terhadap pergantian staf lapangan:

Role Sistem
Jumlah Akun
Cakupan Data (Security Filter)
Hak Akses & Wewenang Utama
KASIR

Foto logbook TTD mitra subuh, input MASUK_KASIR (05.00–07.00), input SISA_KASIR (11.00–13.30), kirim laporan WA 11.30, input Blind Closing, pengeluaran laci, dan foto slip setor.
SPV

ADMIN_PUSAT

1.2. Siklus Status Harian (End-to-End State Machine)
Setiap hari operasional cabang berjalan melewati 5 status terkunci secara berurutan:



[1. OPEN_INBOUND] (05.00 - 07.00 WIB)
   └─ Kasir foto logbook TTD mitra + input MASUK_KASIR. Lewat 07.00 WIB, MASUK_KASIR terkunci.
        │
        ▼
[2. OPEN_CLOSING] (11.00 - 13.30 WIB)
   └─ Pukul 11.00 WIB kolom SISA_KASIR terbuka. Pukul 11.30 WIB share laporan WA grup cabang.
   └─ SPV dapat mengisi kolom koreksi sebelum 13.30 WIB & sebelum bukti setor diunggah.
        │
        ▼
[3. MENUNGGU_CEK_SPV] (Maksimal 13.30 WIB)
   └─ Kasir mengisi Blind Closing (Pengeluaran Laci + Cash Fisik + QRIS + Foto Slip Setor).
   └─ Seluruh input kasir & koreksi SPV terkunci permanen.
        │
        ▼
[4. TERVERIFIKASI_SPV] (13.30 - 14.30 WIB)
   └─ SPV mencocokkan fisik slip setor, penyelesaian minus (nombok/potong gaji), & nota belanja.
        │
        ▼
[5. LOCKED_SETTLED] (14.30 - 15.00 WIB)
   └─ Manager/Owner mengonfirmasi dana masuk pada mutasi rekening pusat.
   └─ Transaksi sah ditarik ke mesin Rekap Payout 3-Harian (Senin–Rabu & Kamis–Sabtu).

6. GOOGLE APPS SCRIPT PEMELIHARAAN (AUTO-ARCHIVE BULANAN)
Pasang skrip berikut di menu Extensions > Apps Script pada Google Sheets Induk dan atur Time-Driven Trigger berjalan setiap tanggal 5 pukul 02.00 WIB untuk memindahkan transaksi bulan lalu yang sudah LOCKED_SETTLED ke file arsip terpisah agar baris aktif AppSheet selalu di bawah 10.000 baris:

JavaScript

function arsipkanTransaksiBulanan() {
  const ssAktif = SpreadsheetApp.getActiveSpreadsheet();
  const sheetTrx = ssAktif.getSheetByName("4_TRANSAKSI_HARIAN");
  const sheetClosing = ssAktif.getSheetByName("5_CLOSING_SETORAN");
  
  // Ganti ID di bawah dengan ID Spreadsheet Arsip Bulanan L10
  const ID_SPREADSHEET_ARSIP = "ISI_ID_SPREADSHEET_ARSIP_DISINI";
  const ssArsip = SpreadsheetApp.openById(ID_SPREADSHEET_ARSIP);
  const arsipTrx = ssArsip.getSheetByName("ARSIP_TRANSAKSI");
  
  const today = new Date();
  const batasTanggal = new Date(today.getFullYear(), today.getMonth(), 1); // Awal bulan berjalan
  
  // Kumpulkan ID_CLOSING yang sudah LOCKED_SETTLED sebelum bulan berjalan
  const dataClosing = sheetClosing.getDataRange().getValues();
  const settledKeys = new Set();
  for (let i = 1; i < dataClosing.length; i++) {
    const tglClosing = new Date(dataClosing[i][1]);
    const statusClosing = dataClosing[i][18]; // Kolom Status_Closing
    if (tglClosing < batasTanggal && statusClosing === "LOCKED_SETTLED") {
      settledKeys.add(dataClosing[i][0]);
    }
  }
  
  // Pindahkan baris transaksi yang sudah settled ke spreadsheet arsip
  const dataTrx = sheetTrx.getDataRange().getValues();
  const barisDipindah = [];
  const indeksHapus = [];
  
  for (let i = 1; i < dataTrx.length; i++) {
    const tglTrx = new Date(dataTrx[i][1]);
    const cabangId = dataTrx[i][2];
    const keyCek = Utilities.formatDate(tglTrx, "GMT+7", "yyyyMMdd") + "-" + cabangId;
    
    if (tglTrx < batasTanggal && settledKeys.has(keyCek)) {
      barisDipindah.push(dataTrx[i]);
      indeksHapus.push(i + 1);
    }
  }
  
  if (barisDipindah.length > 0) {
    arsipTrx.getRange(arsipTrx.getLastRow() + 1, 1, barisDipindah.length, barisDipindah[0].length)
            .setValues(barisDipindah);
    for (let j = indeksHapus.length - 1; j >= 0; j--) {
      sheetTrx.deleteRow(indeksHapus[j]);
    }
  }
}
